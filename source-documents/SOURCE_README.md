# SOURCE DOCUMENTS

## Canonical source

`Hồ sơ giới thiệu thôn Hòa Phú.docx`

Đây là **nguồn nội dung chuẩn** của website ở giai đoạn hiện tại.

Không sửa trực tiếp file này trong quá trình code.

Nếu địa phương cung cấp bản mới:

1. giữ bản cũ để đối chiếu nếu cần;
2. thay/cập nhật canonical source có version/date rõ;
3. rà lại những section website chịu ảnh hưởng;
4. cập nhật `PROJECT_MEMORY.md`.

## extracted-media/

Thư mục này chứa ảnh được trích nguyên trạng từ `word/media/` của file DOCX để coding agent dễ kiểm kê asset.

### Lưu ý

- Tên `image01`, `image02`... không mô tả nội dung.
- Đây là asset tham chiếu kỹ thuật, không đồng nghĩa đã xác minh bản quyền public.
- Không được dùng các ảnh này làm căn cứ cho dữ liệu lịch sử nếu text nguồn không hỗ trợ.
- Với ảnh poster có số điện thoại/cán bộ, không tự public thông tin cá nhân.
